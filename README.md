## Compile options

-0 -> название выходного файла
-Wall -> включает большинство предупреждений
-Wextra -> дополнительные предупреждения (более строигие проверки)

-Werror -> Все предупреждения становятся ошибками — компиляция прерывается
-std=c17 -> (-std=c11, -std=c99) - Задаёт стандарт C

-O0, -O1, -O2, -O3, -Os -> Оптимизация:
    -O0 (дефолт) — без оптимизации, быстро компилируется
    -O2 — хороший баланс скорость/размер
    -O3 — максимальная оптимизация
    -Os — оптимизация по размеру

-g -> Добавляет отладочную информацию для GDB (debug)
-I -> Добавляет директорию для поиска заголовков
-L -> Добавляет директорию для поиска библиотек
-l -> Подключаем библиотеку

-lm -> Ликовка с мат библиотекой
